Proton VPN-Next — это неофициальный клиент для сервисов Proton VPN с открытым исходным кодом, созданный для стабильной работы даже в самых ограниченных сетях.

Ключевые особенности:
- Протокол AmneziaWG: Улучшенный WireGuard с обфускацией, устойчивой к DPI.
- Обход блокировок API: Множество стратегий (Netlify, Cloudflare, WARP, прокси) для доступа к серверам, даже если официальные API заблокированы.
- Дизайн Material You: Современный интерфейс с поддержкой множества тем (Amoled, Gold и стилизации под другие VPN).
- Раздельное туннелирование: Выбирайте, какие приложения или IP-адреса должны работать через VPN.
- Kill Switch: Поддержка системного Kill Switch для предотвращения утечек данных.

Внимание: Этот проект НЕ связан с Proton AG.
